# Project instructions

- Use Rust for the native app and game. No browser shell or Python runtime.
- Use branches and pull requests for future repository changes.
- Keep gameplay deterministic and separate from rendering, sound and persistence.
- Follow docs/ARCADE_STANDARD.md. Record material choices in DECISIONS.md.
- Keep artwork, maze layout and audio original; do not bundle commercial game resources.
- Verify real native input and rendering, and distinguish Linux headless checks from a real Omarchy desktop pass.
- Package updates must preserve local scores, settings and sessions.
