# Artwork provenance

The game rules, maze and vector Original pack were authored for this project.
No commercial game ROM, sprite, maze, recording or official Omarchy logo is
included.

Tom selected the Latch concept in the design conversation. The player,
pursuer atlas and launcher icon were produced with OpenAI Image Generation
from that approved concept. Follow-up edits replaced generated checkerboard
backgrounds with a near-magenta colour key for actor atlases and opaque
charcoal for the launcher. The PNGs are the unmodified generated outputs.
The runtime interprets their colour key and applies OpenGL mipmap filtering;
pack manifests specify frame positions. See ARTWORK-PACKS.md for the format.

The default art is included under this repository's MIT licence. The pack
manifest preserves its generator credit. User-installed packs retain the
author and licence metadata supplied by their makers.

The native game and integration were built with Codex assistance. Dependency
licences, including the fonts distributed by egui, are collected in
THIRD_PARTY_LICENSES.txt.
